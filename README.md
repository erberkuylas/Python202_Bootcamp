# Python OOP Kütüphane Yönetim Sistemi

Bu proje, Python ile **OOP (Nesne Yönelimli Programlama)** yaklaşımı kullanılarak geliştirilmiş basit bir kütüphane yönetim sistemidir.  
FastAPI ile API uç noktaları sağlanmış ve unittest + pytest ile testler yapılmıştır. Ayrıca, bir **manuel CLI (Command Line Interface)** üzerinden de kitap ekleme, silme, listeleme ve arama yapılabilir.

---

## Özellikler

- Kitap ekleme, silme, listeleme ve arama
- ISBN bazlı kitap yönetimi
- FastAPI ile REST API entegrasyonu
- JSON dosyasında veri saklama
- Birim testler ve mock kullanımı ile test edilebilirlik
- Basit ve kullanıcı dostu CLI arayüzü
